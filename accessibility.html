Accessibility Statement

Effective date: 7 September 2026

1. Our commitment

GAVRIQ Labs Global aims for this Website to be usable by as many people as possible, including people with disability. We target conformance with WCAG 2.2 Level AA.

2. What we aim to support

  • Keyboard navigation for all interactive elements
  • Visible keyboard focus indicators
  • Semantic HTML structure
  • Meaningful, logically ordered headings
  • Descriptive alt text for informative images
  • Appropriate colour contrast
  • Support for browser text resizing
  • Accessible, clearly labelled interactive controls
  • Accessible forms with associated labels and status messaging
  • Respect for a visitor's reduced-motion preference
  • Responsive layouts that work across common screen sizes
  • Compatibility with common screen readers

3. Ongoing work

Accessibility is an ongoing process rather than a one-off task. As the Website evolves, we aim to review new content and functionality against these goals before and after release.

4. Known limitations

Despite our efforts, some parts of the Website may not yet fully meet every WCAG 2.2 AA success criterion. We welcome reports of specific issues so we can address them.

5. Reporting an accessibility issue

If you experience difficulty using any part of this Website, please email admin@gavriqlabsglobal.com with the subject line ACCESSIBILITY: Website Issue, including the page and a description of the problem you encountered.

6. Related pages

See our Privacy Policy and Terms of Use for related information.
