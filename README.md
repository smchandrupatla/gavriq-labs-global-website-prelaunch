# GAVRIQ Labs Website

A responsive static website for GAVRIQ Labs.

## Brand positioning
GAVRIQ Labs is presented as a technology and innovation company focused on AI, intelligent automation, research and modern software engineering.

## Brand expansion used in the website
- G — Generative AI
- A — Advanced Intelligence
- V — Vision
- R — Reasoning
- I — Innovation
- Q — Quality


## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Deployment
This site can be deployed directly to GitHub Pages, Azure Static Web Apps, Netlify, Vercel, Cloudflare Pages, or any standard web host.

## Contact form
The contact form is currently front-end only. Connect it to your preferred backend, form service, or email workflow before production use.
